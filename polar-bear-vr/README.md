# 🐻‍❄️ عالم الدب القطبي — فيلم ثلاثي الأبعاد للواقع الافتراضي

فيلم تعليمي قصير (حوالي 3 دقائق) ثلاثي الأبعاد يعمل في متصفح نظارة **Meta Quest 2** (WebXR)، وعلى الحاسوب أو الكروم بوك أيضًا.

## المحتوى
1. مرحبًا بكِ في القطب الشمالي
2. الدب القطبي: أكبر مفترس على اليابسة
3. سرّ الفراء الأبيض والجلد الأسود وطبقة الدهن
4. ماذا يأكل الدب القطبي؟ (الفقمات وحاسة الشم)
5. الصيد بالصبر عند فتحة التنفس
6. طاقة للبقاء دافئًا
7. سبّاح ماهر (من الثدييات البحرية)
8. الأم وصغارها في الوكر الثلجي
9. الخطر الأكبر: ذوبان الجليد البحري
10. ماذا نستطيع أن نفعل؟
11. اختبار قصير من 3 أسئلة مع النتيجة

## طريقة التشغيل
- **على نظارة Meta Quest 2:** افتحي رابط الصفحة في متصفح النظارة (Meta Quest Browser) واضغطي «ابدئي الفيلم»، ثم وافقي على الدخول إلى الواقع الافتراضي. انظري حولك بحرية؛ الطالبة تبقى ثابتة في مكانها (لا دوار).
- **على الحاسوب/الكروم بوك:** اضغطي «ابدئي الفيلم» واسحبي بالفأرة للنظر حولك.
- **الانتقال للمشهد التالي:** وجّهي شعاع اليد إلى لوحة النص واضغطي الزناد (أو انقري بالفأرة، أو زر المسافة).
- **الاختبار:** وجّهي الشعاع إلى الإجابة واضغطي الزناد.

## ملاحظات تقنية
- ملف واحد `index.html` مبني بمكتبة A-Frame 1.5 (تُحمَّل من الإنترنت)، لذلك تحتاج النظارة إلى اتصال بالإنترنت.
- جميع المجسّمات (الدب، الفقمة، الجليد، الشفق القطبي، الثلج) مرسومة بالكود، بلا ملفات خارجية.
- صوت رياح هادئ مُولَّد بالكود. القراءة الصوتية العربية تعمل فقط إذا كان الجهاز يحتوي صوتًا عربيًّا.
- للنشر على GitHub Pages: ضعي المجلد داخل مستودع المكتبة، وسيعمل الرابط مباشرة لأن WebXR يتطلب HTTPS.
