# 📚 مكتبة جواد النشاشيبي

أنظمة خبيرة، وغرف هروب، وألعاب تعليمية، وامتحانات تفاعلية في الذكاء الاصطناعي والعلوم والرياضيات والبرمجة، من إعداد المعلم **جواد النشاشيبي**.

**افتح المكتبة:** https://jawadnashashibi.github.io/jawad-library/

## محتويات هذا المستودع

| المجلد / الملف | الوصف |
|----------------|-------|
| `index.html` | الصفحة الرئيسية للمكتبة |
| `cv.html` | السيرة الذاتية |
| `graph-escape/` | غرفة هروب: مختبر الرسوم البيانية (الصفان 8 و9) |
| `euler-house/` | البيت السحري: مسار أويلر |
| `containment/` | الاحتواء العاطفي والتربوي |

كل المشاريع صفحات ويب تعمل مباشرة في المتصفح، على الحاسوب والكروم بوك والهاتف، دون تثبيت.
